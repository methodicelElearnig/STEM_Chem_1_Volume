# לומדת נפח — מדידת נפח בתחנת העגינה (STEM, כיתות ו׳–ח׳)

לומדה אינטראקטיבית (HTML/CSS/JS) בעברית (RTL), חבילת **SCORM 1.2**, ציון מעבר 80.

- **נקודת הכניסה (SCO):** `index.html`
- **מבנה:** 28 מסכים (`data-screen="1..28"`) — סרטוני דמויות עם כתוביות, מסכי תוכן/דיאלוג,
  שאלות אינטראקטיביות (בחירה, רב-בחירה, גרירה, תפריטים), יישומונים, ומסך סיום ששולח את הציון.
- **ניקוד:** סה״כ 100 (8 שאלות; חלקן מפוצלות). דיווח ל-LMS דרך `js/scorm.js`.
- **נגישות:** WCAG 2.1 AA / ת״י 5568 — כתוביות + בקרת השמעה לסרטונים, ניווט מקלדת, פוקוס נראה.
- **תרגום:** כל הטקסט "חי" (ניתן לחילוץ). מנגנון XLIFF בתיקיית `../i18n/`.

נכסים: `assets/images/`, `assets/video/`, `assets/` (קריינות). מניפסט SCORM: `imsmanifest.xml` + סכמות ה-XSD.
